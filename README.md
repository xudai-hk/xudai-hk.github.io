# Zihan Xu — Personal Website

A minimal, single-screen personal website for graduate study applications.

## Content policy

- The full portfolio PDF is intentionally not published.
- GPA and class rank are intentionally omitted.
- Manuscripts currently under review are intentionally omitted.
- Project and experience sections are intentionally omitted.
- Public contact details are included with the owner's approval.

## Publish with GitHub Pages

This directory is designed to be the root of the public repository
`xudai-hk/xudai-hk.github.io`. GitHub Pages will serve `index.html` directly
from the repository.

No build step or JavaScript is required.
